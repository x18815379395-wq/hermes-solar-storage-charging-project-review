# 光储充一体化项目审查

审查光储充项目能量平衡、收益、融资与租赁风险。

## 安装

方式一（通过Hermes技能中心）：

```bash
hermes skills install https://raw.githubusercontent.com/x18815379395-wq/hermes-solar-storage-charging-project-review/main/SKILL.md
```

方式二（手动安装，从GitHub克隆）：

```bash
git clone https://github.com/x18815379395-wq/hermes-solar-storage-charging-project-review.git ~/.hermes/skills/financial-risk/solar-storage-charging-project-review
hermes reload-skills
```

> 注意：`hermes skills install` 方式需要Hermes Agent支持从GitHub URL安装SKILL.md。若不支持，请使用手动克隆方式。

## 使用方法

覆盖光伏+储能+充电桩一体化能量平衡模型（自发自用/余电上网/峰谷套利）、综合收益测算（含补贴、绿证、辅助服务）、多源现金流分析、设备统一运维与保险、关联方交易风险审查。

具体使用方法请参考技能的 `SKILL.md` 文件。
